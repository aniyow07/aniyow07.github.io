Winsearch

Fast, local filename search for Windows 10 and 11, with a built-in preview pane.

RUSTSQLITEWIN322026

The problem

Windows search is slow and noisy when you just want a file by name. Winsearch answers instantly and lets you check the file without opening it.

How it works

  • Keeps its own index of file and folder names in SQLite, so a search never scans the disk.
  • Previews render in the background for the selected file only: images, PDFs, Word and Excel without Office, and code.
  • Fully local, no admin rights, no telemetry.
